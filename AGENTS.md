# Documentation project instructions

## About this project

- The source of docs.shoply.gg, a [Mintlify](https://mintlify.com) site. Pages are MDX with YAML frontmatter, and `docs.json` is the configuration.
- **A push to `main` publishes the site.** Commit freely, push only when asked to.
- `api-reference/openapi.json`, `api-reference/permissions.mdx`, `api-reference/webhook-events.mdx` and the route groups of the "API reference" tab in `docs.json` are generated by `backend/api-docs.php` in the main Shoply repository. Never edit them here.
- A link to a route's page is `/api-reference/<its group>/<its summary>`, both in small letters with dashes, as the generator writes them.

## Terminology

- "Store", not "shop". "Storefront" is a store's site, of which a store can hold several.
- "Variant" is an option of a product. "License keys" are what a variant has in stock.
- "API key" is the secret key (`shoply_sk_...`). "Permission" in sentences, `scope` only where the API's own field is meant.
- "Webhook endpoint" is where deliveries go. "Delivery" is one event on its way to one endpoint.
- "Checkout Kit" and "embed" are Shoply's own names. Never another platform's names for the same idea.

## Style preferences

- Use active voice and second person ("you").
- One idea a sentence. Plain words.
- Sentence case for headings.
- No em or en dashes anywhere.
- Bold for what is on screen: **Developers**, then **API keys**.
- Code formatting for file names, commands, paths, fields and values.
- Original wording. Do not copy or closely follow another platform's docs.

## Content boundaries

- Nothing about the platform owner's admin panel, the server, or how Shoply is hosted.
- No secret of any kind, real or realistic. Example keys are `shoply_sk_...`.
- Do not describe something as working that the main repository says is not live yet.
