A key carries the permissions you tick when you make it, and reaches a route only when it carries that route's permission. Each route's page says which it needs. You can change a key's permissions afterwards, under **Developers** in the dashboard.

Give a key only what its job needs. A script that reads orders for a report has no use for `orders.refund`.

## Store

| Permission | In the dashboard | What it reaches |
| - | - | - |
| `store.read` | Read store | The store's details, branding and settings. |
| `store.write` | Change store | Change the store's details, branding, address and domain. |
| `payments.read` | Read payment methods | Which payment methods are connected and switched on. Never their credentials. |
| `payments.write` | Change payment methods | Switch payment methods on and off and sort them. Never their credentials. |
| `analytics.read` | Read analytics | Visits, revenue figures, the live view and search reports. |

## Catalogue

| Permission | In the dashboard | What it reaches |
| - | - | - |
| `products.read` | Read products | Products, their variants, pictures and stock counts. |
| `products.write` | Change products | Add, change, sort and delete products, variants and pictures. |
| `stock.read` | Read stock | The license keys and files a variant has in stock, unsold ones included. |
| `stock.write` | Change stock | Add, replace and remove a variant's license keys and files. |
| `categories.read` | Read categories | Product categories and what is in them. |
| `categories.write` | Change categories | Add, change, sort and delete product categories. |

## Orders

| Permission | In the dashboard | What it reaches |
| - | - | - |
| `orders.read` | Read orders | Orders with what was bought, what was delivered and the buyer's details. |
| `orders.write` | Change orders | Write an order's note. |
| `orders.fulfil` | Deliver orders | Mark an order as paid, deliver it again and send its email again. |
| `orders.refund` | Refund orders | Refund an order, to what paid for it or as store credit. |
| `invoices.read` | Read invoices | Invoices the store has raised. |
| `invoices.write` | Raise invoices | Raise an invoice for a buyer to pay, and send it. |
| `reviews.read` | Read reviews | Reviews buyers have left. |
